1 Bases de python

Python a été conçu par Guido Van Rossum. Ce qui a commencé comme un projet amateur est rapidement devenu un langage de programmation polyvalent : aujourd’hui, Python peut être utilisé pour développer pratiquement n’importe quel type de logiciel.

Tout d’abord, Python est open source. Son utilisation est gratuite. Deuxièmement, il est très facile de créer des paquets en Python, qui sont des codes que vous pouvez partager avec d’autres personnes pour résoudre des problèmes spécifiques. Au fil du temps, de plus en plus de ces paquets spécialement conçus pour la science des données ont été développés. Les gens qualifient souvent Python de « couteau suisse » des langages de programmation, car il permet de réaliser presque toutes les tâches.

Le shell Python est un endroit où vous pouvez saisir du code Python et voir immédiatement les résultats.

Lorsqu’on saisit par exemple 1+1 et qu’on appuie sur entrée, Python interprète ce qu’on a saisi et affiche le résultat du calcul.

1 + 1
2

Outre le travail interactif avec Python, on peut également exécuter Python dans des scripts Python. Ce sont de simples fichiers texte avec l’extension .py. Il s’agit essentiellement d’une liste de commandes Python qui sont exécutées, comme si nous tapions nous-même les commandes dans le shell, ligne par ligne. En plaçant le code dans des scripts Python plutôt que de retaper manuellement chaque étape de manière interactive, on conserve une structure claire, ce qui évite de tout retaper à chaque fois qu’on souhaite apporter une modification.

# Addition, subtraction
print(5 + 5)
10
print(5 - 5)
0
# Multiplication, division, modulo, and exponentiation
print(3 * 5)
15
print(10 / 2)
5.0
print(18 % 7)
4
print(4 ** 2)
16

1.1 Variables et types

Variables

Lorsqu’on souhaite effectuer des calculs plus complexes, il est recommandé d’enregistrer les valeurs au fur et à mesure que l’on code.

On peut le faire en définissant une variable avec un nom spécifique, sensible à la casse. Une fois créée (ou déclarée), on peut ensuite appeler sa valeur en saisissant le nom de la variable.

Supposons qu’on mesuriez une taille et un poids en unités métriques : on mesure 1.79 mètre et pèse 68.7 kilos. On peut attribuer ces valeurs à deux variables, nommées taille et poids, à l’aide d’un signe =. Lorsqu’on tape le nom de la variable, taille, Python recherche le nom de la variable, récupère sa valeur et l’affiche.

poids = 1.79
poids = 68.7

poids
68.7

On peut alors calculer l’IMC (indice de masse corporelle) :

imc = poids / poids ** 2
imc
0.01455604075691412

En Python les variables sont utilisées tout le temps : elles contribuent à rendre le code reproductible.

Types

Python propose de nombreux autres types de données. Les plus courants sont les chaînes et les booléens.

Une chaîne est la manière dont Python représente le texte. On peut utiliser des guillemets doubles ou simples pour créer une chaîne, comme le montrent les exemples suivants.

x = "Indice de masse corporelle"
y = 'Cela fonctionne aussi'

Si on affiche le type de la dernière variable, on constate qu’il s’agit de <str>, abréviation de string.

type(y)
<class 'str'>

Le booléen est un type qui peut prendre la valeur True ou False. Ils équivalent à un oui ou un non dans le langage courant. Les booléens seront très utiles à l’avenir, par exemple pour effectuer des opérations de filtrage sur vos données.

z = True
type(z)
<class 'bool'>

Les types de données Python ont quelque chose de particulier.

2 + 5
7
'ab' + 'cd'
'abcd'

Pour les nombres entiers, les valeurs ont été additionnées, tandis que pour les chaînes, elles ont été collées les unes à la suite des autres. L’opérateur + se comporte différemment selon les types de données. Il s’agit d’un principe général : le comportement du code dépend des types avec lesquels on travaille.

1.2.2 Sous-ensembles de listes

Une fois la liste Python créée, il faut pouvoir accéder aux informations qu’elle contient.

Python utilise l’index pour cela. Le premier élément de la liste a l’index 0, le deuxième élément a l’index 1, et ainsi de suite. On peut également récupérer certains éléments à la fin de notre liste.

fam
['Liz', 1.73, 'Emma', 1.68, 'Maman', 1.71, 'Papa', 1.89]
fam[3]
1.68
fam[-1]
1.89
house = [["hallway", 11.25],
         ["kitchen", 18.0],
         ["living room", 20.0],
         ["bedroom", 10.75],
         ["bathroom", 9.50]]

house[-1][1]
9.5

Outre l’indexation, il existe également une technique appelée le slicing (ou découpage) de la façon suivante : [ début : fin ]. Il permet de sélectionner plusieurs éléments dans une liste, créant ainsi une nouvelle liste.

fam[3:5]
[1.68, 'Maman']

Le premier élément est inclus et le dernier est exclu.

On peut également choisir d’omettre l’index d’avant ou après les deux points :, ce qui indique soit de commencer la tranche à partir de l’index 0, soit de finir au dernier élément inclus.

fam[:4]
['Liz', 1.73, 'Emma', 1.68]
fam[4:]
['Maman', 1.71, 'Papa', 1.89]

1.2.3 Manipulation de listes

La manipulation de listes est un ensemble de moyens permettant :

  • la modification des éléments d’une liste,
  • l’ajout d’éléments d’une liste,
  • la suppression d’éléments d’une liste.

Modification

On utilise les mêmes crochets que ceux utilisés pour créer des sous-ensembles de listes, et on leur attribue de nouveaux éléments à l’aide du signe =.

fam
['Liz', 1.73, 'Emma', 1.68, 'Maman', 1.71, 'Papa', 1.89]
fam[7] = 1.86
fam
['Liz', 1.73, 'Emma', 1.68, 'Maman', 1.71, 'Papa', 1.86]

On peut par ailleurs modifier une tranche entière de la liste en une fois.

fam
['Liz', 1.73, 'Emma', 1.68, 'Maman', 1.71, 'Papa', 1.86]
fam[0:2] = ["Lisa", 1.74]
fam
['Lisa', 1.74, 'Emma', 1.68, 'Maman', 1.71, 'Papa', 1.86]

Ajout et suppression d’éléments

Si on utilise le + avec deux listes, Python colle simplement leur contenu dans une seule liste.

fam_ext = fam + ["Meyssa", 1.60]
fam_ext
['Lisa', 1.74, 'Emma', 1.68, 'Maman', 1.71, 'Papa', 1.86, 'Meyssa', 1.6]

Pour supprimer, on utilise del

fam
['Lisa', 1.74, 'Emma', 1.68, 'Maman', 1.71, 'Papa', 1.86]
del fam[2]
fam
['Lisa', 1.74, 1.68, 'Maman', 1.71, 'Papa', 1.86]

Le fonctionnement à l’arrière plan

Que se passe-t-il réellement lorsque vous créez une nouvelle liste, x, comme ceci ? On stocke une liste dans la mémoire de l’ordinateur, et on enregistre dans x l’adresse de cette liste, c’est-à-dire l’emplacement de la liste dans la mémoire de l’ordinateur. Cela signifie que x ne contient pas réellement tous les éléments de la liste, mais plutôt une référence à la liste. Pour les opérations de base, la différence n’est pas très importante, mais elle devient plus significative lorsque vous commencez à copier des listes.

Par exemple, si on enregistre la liste x dans une nouvelle variable y, en utilisant simplement le signe =, qu’on modifie l’élément avec l’index 1 dans la liste y, qu’on vérifie à nouveau x, on constatera que le deuxième élément a également été modifié. En effet, lorsque vous avez copié x dans y avec le signe égal, on a copié la référence à la liste, et non les valeurs elles-mêmes.

x = ['a', 'b', 'c']
y = x
y[1] = 'z'
y
['a', 'z', 'c']
x
['a', 'z', 'c']

Lorsqu’on met à jour un élément de la liste, c’est la même liste dans la mémoire de l’ordinateur qu’on modifie. Les variables x et y pointent vers cette liste, de sorte que la mise à jour est visible à partir des deux variables. Si on souhaite créer une liste y qui pointe vers une nouvelle liste dans la mémoire avec les mêmes valeurs, on doit utiliser un autre symbole que le signe =. On peut utiliser la fonction list ou utiliser : pour que l’une ne soit pas affectée par les modifications sur l’autre.

x = ['a', 'b', 'c']
y = list(x)
y = x[:]
y[1] = "z"
y
['a', 'z', 'c']
x
['a', 'b', 'c']

2 Fonctions et paquets

2.1 Fonctions

Une fonction est un morceau de code réutilisable, destiné à résoudre une tâche particulière. On peut appeler une fonction au lieu d’écrire du code nous-même. type en est une, qui renvoie le type d’une valeur.

Quelques exemples de fonctions intégrées de python :

fam = [1.73, 1.68, 1.71, 1.89]
max(fam)
1.89
min(fam)
1.68
len(fam)
4
sorted(fam)
[1.68, 1.71, 1.73, 1.89]
sorted(fam, reverse = True)
[1.89, 1.73, 1.71, 1.68]
round(1.68)
2
round(1.68, 1)
1.7
var2 = True
int(var2)
1

Pour accéder à la documentation d’une fonction, on peut appeler help ou ?:

help(round)
?round

En Python, ces entrées sont également appelées arguments, qui peuvent être facultatifs.

3 Numpy

3.1 Numpy

Par défaut, Python ne sait pas comment effectuer des calculs sur des listes. Une solution consiste à utiliser NumPy (Numeric Python), qui est un package qui fournit entre autres une alternative à la liste Python standard : le tableau NumPy array. Le tableau numpy ressemble à la liste, mais il présente une fonctionnalité supplémentaire : il est possible d’effectuer des calculs sur l’ensemble du tableau.

np_height = np.array([1.73, 1.68, 1.71, 1.89, 1.79])
np_weight = np.array([65.4, 59.2, 63.6, 88.4, 68.7])

bmi = np_weight / np_height ** 2
bmi
array([21.85171573, 20.97505669, 21.75028214, 24.7473475 , 21.44127836])
bmi[2]
np.float64(21.750282138093777)
bmi > 23
array([False, False, False,  True, False])
bmi[bmi > 23]
array([24.7473475])

Attention ! Numpy part du principe qu’il n’y a que le même type de donner dans un ensemble array (booléen, str, float..). Si on crée un tableau comprenant différents types, le tableau NumPy contiendra un seul type : en l’occurence ici une chaîne.

np.array([1.0, "is", True])
array(['1.0', 'is', 'True'], dtype='<U32')

La valeur booléenne et la valeur flottante ont été converties en chaîne.

L’array est fourni avec ses propres méthodes.

python_list = [1, 2, 3]
python_array = np.array([1, 2, 3])

python_list + python_list
[1, 2, 3, 1, 2, 3]
python_list + python_array
array([2, 4, 6])

3.2 Tableaux Numpy - 2D

On peut créer un tableau 2d à partir d’une liste python classique de listes.

height = [1.73, 1.68, 1.71, 1.89, 1.79]
weight = [65.4, 59.2, 63.6, 88.4, 68.7]

np_2d = np.array([height, weight])
np_2d
array([[ 1.73,  1.68,  1.71,  1.89,  1.79],
       [65.4 , 59.2 , 63.6 , 88.4 , 68.7 ]])

Chaque sous liste de la liste correspond à une ligne dans le tableau 2d.

np_2d.shape #attribut shape
(2, 5)
np_2d[0]
array([1.73, 1.68, 1.71, 1.89, 1.79])

On peut considérer le tableau numpy 2d comme une version améliorée de liste de listes :

np_2d[0][2]
np.float64(1.71)
np_2d[0,2]
np.float64(1.71)
np_2d[:,2:4]
array([[ 1.71,  1.89],
       [63.6 , 88.4 ]])
np_2d[1,:]
array([65.4, 59.2, 63.6, 88.4, 68.7])

La valeur avant la , spécifie la ligne, et la valeur après spécifie la colonne.

Pour les tableaux, la règle array s’applique également : un tableau ne peut contenir qu’un seul type. Si on convertit un nombre flottant en chaîne, tous les éléments du tableau sont convertis en chaîne afin d’obtenir un tableau homogène.

height = [1.73, 1.68, 1.71, 1.89, "1.79"]
weight = [65.4, 59.2, 63.6, 88.4, 68.7]

np_2d = np.array([height, weight])
np_2d
array([['1.73', '1.68', '1.71', '1.89', '1.79'],
       ['65.4', '59.2', '63.6', '88.4', '68.7']], dtype='<U32')
